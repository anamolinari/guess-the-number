## About

<p align="justify">
Pixel-perfect implementation of a Figma design, built with vanilla HTML, CSS, and JavaScript. The game generates a random number using <code>Math.floor(Math.random() * 100) + 1</code> and challenges the player to guess it within 5 attempts, with real-time feedback after each guess.
</p>

---

## Features

- Random number generation between 1 and 100
- Up to 5 attempts per round with real-time high/low feedback
- Input via virtual keyboard, mouse, or physical keyboard
- Strict input validation — rejects letters, special characters, negative numbers, and values above 100
- Previous guesses remain visible on screen throughout the game
- Victory message in green, defeat message in red
- Play again option available at the end of every round
